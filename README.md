# 本日の開催情報

朝礼向けの1920×1080固定レイアウト。大きな日付と4つの情報枠（競輪、オートレース、SODA対象ボートレース、森且行選手の出走予定）を表示します。画面サイズに応じて同じ比率で縮小表示します。

## 公開URL

https://nobusukeyanagi.github.io/assembly/

**初回だけ** リポジトリの [Settings → Pages](https://github.com/nobusukeyanagi/assembly/settings/pages) にある **Build and deployment > Source** を **GitHub Actions** に変更してください。その後、[Actions → 本番公開・日次更新](https://github.com/nobusukeyanagi/assembly/actions/workflows/refresh.yml) から `Run workflow` を実行します。初回の Pages 有効化は `GITHUB_TOKEN` だけでは行えません。

## スタイル管理

- `styles.css` に共通の色・レイアウト変数を定義し、利用箇所から `var(--...)` で**直接参照**します。変数同士の別名・多段参照は作りません。白色は `--white`、基本文字色は `--ink`、開催場と競技見出しの間隔は `--tile-gap` に統一しています。
- 使用するフォントサイズは **30・60・80px**。共通変数 `--font-30`・`--font-60`・`--font-80` に定義し、すべての文字サイズ指定から `var(--font-*)` で直接参照します。変数同士の間接参照は行いません。
- 開催場のグレードラベルは **高さ35px**。出走表では共通ラベルを利用しつつ高さ80pxへ上書きします。
- 未使用の補助文字変数は廃止。競技見出しは各競技帯の背景色と文字色をそのまま継承します。
- 競技帯の高さと場枠の高さは、開催場数から算出した行数と既存の共通レイアウト変数で管理します。

## 自動更新

- 毎日 **01:10 JST** に当日情報を更新し、日付指定表示から当日表示へ戻します。さらに **13:10・23:40 JST** に当日の情報を再取得し、過去日照合用の記録を蓄積します（両時刻では表示日付を変更しません）。GitHub Actions の実行開始には遅延があり得ます。
- `main` ブランチの HTML / CSS / JS / 収集スクリプトの変更時も自動実行し、公開サイトを更新します。
- 手動更新: **Actions → 本番公開・日次更新 → Run workflow**。
- 生成データ: `data/today.json`。画面は10分ごと、再表示時にも公開済みの当日データを読み直します。自動取得・更新はGitHub Actionsで行います。
- **履歴保存:** 日次・手動更新時、確認済みの当日データを `data/history/YYYY-MM-DD.json` に日付別保存します。後日の公開元ページが消えても、同日・同じ開催と確認できる情報だけを参照できます。履歴ファイルはGitHub Pagesの公開配信対象には含めません。
- 昨日以前のデータを当日の開催情報として表示しません。読み込み中および取得・確認待ちの案内文は表示せず、未取得部分を空欄にします。開催がないことを確認できた場合のみ「開催情報がありません」と表示し、推測で埋めません。

## 公開画面の表示切り替え（当日／日付指定）

[Actions → 本番公開・日次更新](https://github.com/nobusukeyanagi/assembly/actions/workflows/refresh.yml) → **Run workflow** から実行します。

- **表示方法**：`当日` または `日付指定` を選択します。初期選択は **`日付指定`** です。
- **日付指定**の場合は日付を `YYYY-MM-DD` で入力します。初期値 `2026-11-23`。
- **当日**の場合、日付入力の値は処理上**無効（無視）**になります。GitHub Actionsの標準フォームは選択内容に応じた入力欄の非活性化に対応していないため、画面上の入力欄は操作できます。
- 実行後、通常の公開URL（https://nobusukeyanagi.github.io/assembly/）の画面自体が切り替わります。画像出力ではありません。
- 日付指定の場合は指定日の実開催情報を取得し、`data/selected.json` を作成します。過去日の競輪は、終了済み開催が消える現行日程ではなく日別の開催記録を利用し、別のレース一覧で時間帯を照合します。サンプルデータは使用しません。取得できない情報源では取得エラーを表示します。
- 日付指定中は画面右上に「日付指定表示」と示します。
- **毎日01:10 JSTの日次更新を優先します。** 日付指定表示中でも、翌日の日次更新で**当日表示に自動復帰**します。日付指定データはその際に削除されます。日次更新が失敗した場合は、公開中の表示が維持されます。
- 手動の日付指定は次の日次更新まで維持します。コード変更に伴う通常の自動公開（push）では、現在の表示方法を変更しません。
- すぐに元に戻す場合は **Run workflow → 当日** を選択します。表示モードの設定は `data/display.json` に保存します。

## スペースキーでグレード決勝出走表に切替

- 競輪のGP・G1・G2・G3と、オートレースのSG・特G1・G1・G2で、**開催最終日かつレース名が「決勝」「優勝戦」**である場合のみ、確認済みの出走表を掲載します。
- **スペースキー**：開催場一覧 → **競輪のグレード決勝** → **オートレースのグレード優勝戦** → **森且行選手の出走レース** → **SODA対象ボートレース場のグレード優勝戦** → 開催場一覧。グレード決勝と森選手のレースが同一の場合は重複しません。出走表未確認のレースは表示しません。
- 日付ヘッダーは場一覧と同じ高さ**100px**・位置を維持し、下段の**1920×960px**（上端120pxから）を使用します。出走表本体は横幅**1600px**、左右の白余白は各160pxです。
- 1行目は**競技色の帯**（競輪は青、オートレースは赤茶、SODAは青緑）で開催節名を表示し、長い名称は80pxを保って横幅だけ圧縮します。2行目は **場一覧と共通のグレードラベル＋場名 R　レース種別　発走時刻**（R番号と種別、種別と時刻の間は全角スペース）で表示。「(枠番選択)」「S級」は決勝の種別から除外、森選手のレースは「予選」「準優勝戦」など取得した種別を表示します。
- 車番には車番別の塗色を適用します。選手欄は左右2列・各列最大5行の固定高さで、6人は左3/右3、7人は左4/右3、8人は左4/右4、9人は左5/右4に配置します。足りない枠は空白です。
- 競輪は[KEIRIN HEXの日別一覧](https://keirinhex.jp/races/20261108/)と同サイトのレース別出走表、オートは[東スポオートレースの当日・場・R指定出走表](https://autorace.tokyo-sports.co.jp/list/race/202611030412)で、日付・開催場・レース番号・決勝の種別・選手名を確認します。検証できないレースは表示せず、取得できた同日データのみを維持します。
- 日付指定でも**指定日**の出走表を取得します。更新時に画面が開いている決勝は、同じレースが引き続き確認できれば表示を維持します。
- 出走表の開催節名・車番・選手名は**80px**、2行目のレース情報とグレードラベルは**60px**です。グレードラベルの色や形状は場一覧と共通とし、サイズのみ拡大します。競輪の選手名末尾の「選手」「地元」を除き、姓名の間にスペースを入れます（一般的な姓の文字数を基準とし、例外姓は補正）。
- 出走取消・欠場・欠車・競走除外を取得元の行表示から確認できた場合、当該選手名に既定の赤色で二重線を重ねます。森且行選手の氏名は既定の赤字です。情報源で確認できない場合は推測しません。
- SODAの出走表は**SG・PG1・G1・G2・G3**のグレード開催最終日のみが対象で、**一般・普通開催は優勝戦でも出走表を作成しません**。対象レースは公式BOAT RACEサイトの12R優勝戦・6人の選手を照合します。**発走時刻**は公式締切時刻とは区別し、「発走」と明記された別ソースから確認できた場合だけ表示します。情報源に発走時刻がない場合は時刻部分を表示せず、締切時刻から推算しません。
- 初回3秒の操作案内は「F11 で全画面表示」「Space Key で出走表表示」の2行をキーボード風に表示します。

## 複数サイトの照合と取得失敗対策

### 情報源の優先順位（項目別）

開催情報は**指定日・開催場が検証できた情報源だけ**を使用します。同一場のレコードでも、グレード・日目・時間帯をそれぞれ独立に選び、以下の優先順位（左から優先）で採用します。取得順序は優先順位に影響しません。

| 競技 | グレード・日目 | 時間帯 | ガールズ・女子開催の検出 |
|---|---|---|---|
| 競輪 | KEIRIN.JP → 楽天Kドリームス → KEIRIN HEX → WINTICKET月別決勝日程 | KEIRIN.JP → KEIRIN.JP公式モーニング日程 → CTC開催日程 → KEIRIN HEX → WINTICKET月別決勝日程 | KEIRIN.JP → CTC開催日程 → KEIRIN HEX → WINTICKET月別決勝日程（肯定情報を重視） |
| オートレース | AUTORACE.JP公式出走表（照合できた場合）→ WINTICKET指定月日程 → オッズパーク日別 | AUTORACE.JP公式出走表（照合できた場合）→ WINTICKET指定月日程 → オッズパーク日別 | 掲載がある場合だけ採用 |
| SODA | **G3はBOAT RACE公式年間G3日程** → BOAT RACE公式日別 → きょうの競艇 | BOAT RACE公式日別 → きょうの競艇 | 公式年間G3日程 → BOAT RACE公式日別 → きょうの競艇（レディース開催の肯定情報を重視） |

- 競輪の過去日は楽天Kドリームスの日付別記録を土台にします。日付別レース一覧に時間帯情報がない場合は、**KEIRIN.JP公式モーニング開催日程**や、対象年月を検証したWINTICKET決勝一覧（2026年10月・11月）から補完します。CTCの開催日程は開催期間・場・グレードを照合し、ページが年を明記しないため**当日から前後65日以内に限って**参照します。CTCの明記したガールズやナイターも検証後に採用します。未確認の月・日付には類推して適用しません。
- どの情報源でも**グレードが異なる開催の時間帯やガールズ情報を混在**させません。ただしSODAでは公式年間G3日程が同日・同場のG3を確認した場合、日別表の「一般」という暫定表記を補正し、日目・時間帯の情報を継続利用します。
- オートレースはWINTICKETの年月別日程を網羅的な基本情報源とし、AUTORACE.JPの**日付・開催場が一致する公式出走表**を独立に取得します。公式の情報と食い違う場合は、公式の確認値を優先します。公式で一致した場数と未照合理由をGitHub Actionsの照合レポートに残します（公式URLの山陽は `sanyou` 表記）。サイト間で異なる場合は両方の値と採用元を記録します。
- **「ガールズ／女子開催が確認できない」ことは「開催しない」と同義ではありません**。該当レース・開催名から明示的に検出できた場合だけアイコンを表示し、未検出分を憶測で追加しません。
- BOAT RACEの年間G3日程は、対象年に属する表・日付範囲・開催場を照合し、別の年の情報を混入させません。森選手の発走時刻も出走日・場・Rが一致する出走表だけから取り、締切時刻から逆算しません。

### 採用元・不一致・欠落の監査

- 各開催場レコードの `fieldSources` に**実際に採用したグレード・日目・時間帯・ガールズの情報源**を保存します。女子開催が確認できた場合は `girlsConfirmedBy` も記録します。
- `sections.*.verification` に `providers`（取得件数）、`crossConfirmed`（同じ場を複数サイトで確認した数）、`gradeCrossConfirmed`（同じグレードを複数サイトで確認した数）、`fieldCoverage`（各項目の取得件数）、`priorityPolicy`（適用した優先順）、`conflicts`（不一致と採用元）、`ignoredFields`（異なるグレードから除外した情報）を記録します。
- GitHub Actionsの照合レポートで、不一致・欠落に加えて**取得元ごとのエラーと採用元**を確認します。1サイトでエラーが起きても、他のサイトから**同日付で検証された情報**を表示できます。CTC開催情報は現在GitHub Actionsの取得環境から403になることがあるため、アクセスできない場合は採用しません。
- **全サイトから取得できなかった場合に限り、同じ日付で過去に正常取得した開催データ全体を再利用**します。また、記録済みの過去日情報や当日の履歴記録と照合し、以前に**同じ日付・場・グレード・整合する日目**で情報源を記録済みだった項目（時間帯・ガールズ等）だけを補完します。復元した項目は `sameDateRestored` に残します。現在日・未来日の部分欠落には適用しません。別の日付のレコードは流用しません。取得不能な項目は空欄とし、確証のない値や「確認中」を表示しません。

**限界：** すべての年月について、全サイトが過去のレース・時間帯・ガールズ・発走時刻を保存・公開しているわけではありません。したがって、**任意の日付の全情報を必ず取得できる保証はありません**。情報源の追加が必要な年月では、公開URLと対象期間を確認して登録します。正確性が確認できない場合は表示を控える設計です。

## 取得元と注意点

| 表示項目 | 取得元 |
|---|---|
| 競輪 | [KEIRIN.JP公式開催日程](https://keirin.jp/sp/raceschedule)、[KEIRIN.JP公式モーニング開催日程](https://keirin.jp/pc/dfw/portal/guest/campaign/morning/index.html)、[競輪公式投票CTC開催情報](https://ctc.gr.jp/schedule/)、過去日の[楽天Kドリームス開催記録](https://keirin.kdreams.jp/kaisai/2026/11/01/)、[KEIRIN HEXの日別レース一覧](https://keirinhex.jp/races/)（提供期間限定）。日付・開催場・グレードの一致を確認して統合 |
| オートレース | [WINTICKETの年月別開催日程](https://www.winticket.jp/autorace/schedules/202610)、[オッズパークの場別レース情報](https://sp.oddspark.com/autorace/SpRaceList.do?joCd=05&kaisaiBi=20261012)、[AUTORACE.JP](https://autorace.jp/) |
| SODA対象場 | SODA対応場を[BOAT RACE公式開催日程](https://www.boatrace.jp/owpc/pc/race/index?hd=20261012)と[きょうの競艇の日別開催記録](https://www.ikachi.org/kyotei/2026-10-12)から検証 |
| 森且行選手 | 当日・未来：[WINTICKET選手プロフィール](https://www.winticket.jp/autorace/autoracer/2529/)・公式あっせん。過去日：[Handicapper.jpの出走履歴](https://handicapper.jp/riders/118)。当日レース時刻：[東スポオートレースの指定日・場・R別出走表](https://autorace.tokyo-sports.co.jp/list/race/20261101045) |

**SODA欄は「SODA対応場で開催されるレース場」です。SODAでそのレースが配信されることを保証しません。**

森選手は場名とR番号を同じ行に60pxで表示します（例：川口 11R／川口 3R・12R）。当日出走の際は、下段の日付を**出走表で確認した発走時刻**（例：12:22／10:30/18:00）に置き換えます。時刻が確認できなければ時刻部分を表示しません。**日付指定で過去日を選択した場合は、[Handicapper.jpの選手別出走履歴](https://handicapper.jp/riders/118)から指定日の実際の出走記録を検索し、当日出走がなければ履歴に記録された次の出走を表示します。** 現在の未来あっせんを過去日の出走情報として流用しません。過去履歴の収録範囲外や取得失敗時は、未確認の案内文を表示せず空欄にします。あっせん日程しか確認できない場合も、確認待ちの文言は表示しません。出走取消・変更の可能性があります。

オートレースの通常開催は「普通」、SODA等の一般開催は「一般」と表示します。曜日は土曜が青、日曜・祝日が赤で、括弧は黒のままです。

**Gamboo** はアクセス確認画面等のため自動取得元には利用せず、各競技の日程ソースを優先しています。

## 構成

- `index.html` 表示画面
- `styles.css` 表示スタイル
- `app.js` JSON読込、日付チェック、画面描画と自動更新
- `scripts/update.py` 日程取得・検証・JSON保存
- `tests/test_update.py` 基本単体テスト
- `.github/workflows/refresh.yml` 01:10 JST自動収集と Pages 本番公開

ローカルで試す場合: `pip install -r requirements.txt` → `python -m unittest discover -s tests` → `python scripts/update.py` → `python -m http.server 8000`。
